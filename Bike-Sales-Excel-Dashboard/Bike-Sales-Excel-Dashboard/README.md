# Bike Sales Dashboard (Excel)

**Goal:** Analyze which customer groups are more likely to buy a bike.
**Tools:** Excel (Pivot Tables, Pivot Charts, Slicers, XLOOKUP/VLOOKUP, Conditional Formatting)
**Dataset:** Bike sales practice dataset (public, used in a learning tutorial)

## What I did
- Cleaned the data and built pivot tables
- Built an interactive dashboard with slicers for education, region, and marital status
- Analyzed income, commute distance, and age against bike purchases

## Key insights
- Bike buyers have a higher average income than non-buyers for both genders.
- Middle-aged customers (31-55) are the largest group, at 331 customers.
- Commute distance has a mixed effect: buyers lead at 0-1 miles, but non-buyers lead at 1-2 and 5-10 miles.
